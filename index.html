What you need to understand before we start

These are non-negotiable realities of running your own mail infrastructure.

1

You register the Hetzner server

You create the Hetzner Cloud (or dedicated) account and provision the server. You then provide me with admin (root / sudo) access so I can install and configure the stack. The server stays in your name and under your billing.

2

IP warmup is mandatory and takes time

A brand-new IP has no reputation. Sending to your entire list on day one will land you in spam folders or get the IP blocked. Proper warmup typically takes 60 to 120 days of gradually increasing volume before you can safely reach your full list. We build the schedule together.

3

Domain reputation matters

A domain with history, clean Postmaster Tools data, and existing good standing dramatically improves deliverability. New or poorly managed domains start from zero.

4

Stack choices

Default recommendation: Mailcow (full mail server) + Listmonk (self-hosted newsletter / campaigns). Happy to use another email management / marketing app if you have a preference.
